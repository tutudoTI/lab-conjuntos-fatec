## 🚀 Sobre o Projeto
O objetivo deste laboratório é aplicar conceitos matemáticos de **Teoria dos Conjuntos** e **Conjuntos Numéricos** na resolução de problemas em linguagem Python[cite: 1]. O projeto divide-se em três partes:
1. **Parte 1**: Implementação manual de operações de conjuntos (união, interseção, diferença, pertinência, inclusão) sem o uso direto dos operadores prontos, validando posteriormente com os recursos nativos (`set`) do Python[cite: 1].
2. **Parte 2**: Classificador de números em conjuntos numéricos ($\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{I}, \mathbb{R}$), além de funções bônus como o Crivo de Eratóstenes para números primos e gerador de divisores[cite: 2, 4].
3. **Parte 3**: Mini-projeto de Integração aplicando o **Índice de Jaccard** para um sistema simples de recomendação de interesses[cite: 2, 4].
